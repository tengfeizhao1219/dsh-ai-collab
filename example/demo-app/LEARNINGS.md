# LEARNINGS · demo-app 教训库

> **目的**：让每个踩过的坑都变成可检索的经验，**同一个坑绝不踩第二次**。
> **规则**：任何修复/返工（≥2 次尝试或 ≥1 小时）完成后，**当次必须**在本库追加一条；新阶段/新模块开工前，相关角色**必读**本库。
> 由修复者本人维护（谁踩坑谁记录）。

---

## 记录格式

```markdown
### [YYYY-MM-DD] 一句话标题（领域：前端/数据/部署/同步…）

- **症状**：表面现象（用户/上游看到什么）
- **根因**：真正原因（挖到底，不是表象；可用 5 Whys）
- **正确做法**：下次遇到应直接怎么做（含代码/配置要点）
- **错误路径**：（可选）走过的弯路，防止他人重走
- **涉及角色**：I / A / P / D / Q / K / O
```
