# REVIEW · demo-app 复盘与持续优化记录

> **目的**：不止于"记录教训"——定期从任务和对话中复盘，提炼效率瓶颈与 AI 能力短板，**反哺优化角色卡/机制/工具/DoD**，让后续任务一轮比一轮高效。
> **触发时机**（任一即可，O 主控负责组织）：
> 1. **关口检查时**（阶段级强制：先跑 review.py 再过关口）
> 2. **批量完成**：每完成 5 个任务
> 3. **模式触发**：同一类返工出现 2 次 / 某区域连续 2 次修复 / 任务 🔁 重试
> 4. **定期**：每周或每阶段末
> **反哺闭环**：每条优化行动必须写「去向」（更新哪个文件/规则），完成打勾——复盘不落地等于没复盘。

## 复盘输入（review.py 自动生成，运行方式）

```bash
python3 scripts/review.py [项目目录]        # 输出复盘输入报告
python3 scripts/review.py --write REVIEW.md # 把统计写入复盘记录（可选）
```

> review.py 从 TASK_BOARD/COMMLOG/LEARNINGS/REVIEW 提取：任务状态分布、阻塞/重试清单、最近交接、教训数、未完成优化行动、模式检测（返工/长期进行中）。
